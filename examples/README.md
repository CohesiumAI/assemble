# Assemble examples

`startup/.assemble.yaml` is a minimal startup-profile configuration for Cursor and Codex. To try it without modifying this repository, copy it into an empty project and run:

```bash
npx cohesiumai-assemble --update --project /path/to/empty-project
```

Review generated files before committing them. MCP, plugins, memory, metrics, and web search are disabled in this minimal example.
